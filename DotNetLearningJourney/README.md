# DotNetLearningJourney

A beginner-friendly C# console project for practicing core .NET concepts and sharing working examples with a mentor. The project targets .NET 8 and keeps the examples runnable from one entry point.

## Run the examples

From this directory, run:

```sh
dotnet run --project DotNetLearningJourney/DotNetLearningJourney.csproj
```

## Topics covered

- **01-Basics:** variables and data types, methods, conditions, `for` and `foreach` loops.
- **02-ClassesObjects:** classes, objects, properties, constructors, and a simple employee directory.
- **03-OOP:** encapsulation, inheritance, polymorphism, and abstraction.
- **04-Interfaces:** an interface, an implementation, and a notification service using that implementation.
- **05-CollectionsGenerics:** arrays, `List<T>`, `Dictionary<TKey, TValue>`, a generic class, and introductory LINQ filtering and sorting.

## Weekly progress

The supplied 24-week plan groups C# fundamentals across Weeks 1–4 and calls out OOP, classes and interfaces, collections, generics, and LINQ. The checklist below tracks the Week 1 and Week 2 portfolio scope requested for this repository; check an item only after reviewing its runnable example.

### Week 1

- [ ] Employee management example

### Week 2
